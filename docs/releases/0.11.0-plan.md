# ATLAS 0.11.0 — Administration and Platform Operations

## Objective

Introduce secure platform administration for managing existing ATLAS users, projects, security events, system health, and operational settings.

## Existing User Integration

The admin module must use the current ATLAS users table and display all existing user records.

No duplicate user table or sample-only user list will be created.

Existing users will retain:

- User ID
- Name
- Email
- Password hash
- Role
- Owned projects
- Project content
- Historical activity

The admin interface will display:

- User ID
- Name
- Email
- Role
- Account status
- Registration date
- Last login date
- Owned project count
- Document count
- Requirement count
- Test-case count
- Release-candidate count
- Recent activity

## Role-Based Access Control

Roles:

- User
- Admin

Rules:

- Admin authorization must be enforced by FastAPI.
- Normal users receive HTTP 403 for admin endpoints.
- New registrations always receive the User role.
- Users cannot promote themselves.
- Suspended users cannot authenticate.
- Existing sessions are invalidated after suspension.
- The final active administrator cannot be demoted or suspended.
- Role and account-status changes are audited.

## User Management

Administrators can:

- Search and filter existing users
- View complete user summaries
- View user-owned projects
- Promote users to Admin
- Demote administrators
- Suspend accounts
- Reactivate accounts
- Invalidate sessions
- Trigger password-recovery email
- View account and security activity

Passwords, password hashes, reset-token hashes, JWT secrets, and SMTP credentials must never be shown.

## Project Oversight

Administrators can:

- Search all projects
- View project owner
- View project status
- View artifact totals
- Archive projects
- Restore projects
- Transfer ownership to another existing user
- Identify failed document processing
- Identify unresolved critical risks
- Inspect project readiness summaries

Project-content editing remains with the project owner.
