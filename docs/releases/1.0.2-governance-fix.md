# ATLAS 1.0.2 Governance and Demo Fixes

## Included

- Added visible project-level deletion control on the project dashboard.
- Project deletion now requires an exact project-name confirmation in the API payload.
- Project deletion writes a platform-level audit event before the project is removed; the audit record survives because the project foreign key uses `SET NULL`.
- Project deletion continues to remove project-scoped database records through SQLAlchemy cascade relationships and removes project upload/vector storage.
- Prevented administrator self-demotion.
- Serialized last-active-administrator checks with row locking to prevent concurrent demotion/suspension from reducing the platform to zero active administrators.
- Added explicit frontend confirmation for administrator promotion/demotion and suspension.
- Changed AI-assisted test generation to accept exactly one test Type per generation request.
- Rejected legacy multi-type generation payloads instead of silently ignoring the obsolete field.
- Added SecureBank maximum requirements and complete demo workflow documents.
