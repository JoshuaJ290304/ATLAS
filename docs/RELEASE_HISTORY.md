# ATLAS Release History

## v0.1.0 — Foundation

Authentication, secure password storage, JWT sessions, PostgreSQL, project ownership, Docker Compose, and the initial React workspace.

## v0.2.0 — Document intelligence

Project-isolated PDF/DOCX upload, validation, checksums, metadata, text extraction, download, and deletion.

## v0.3.0 — Requirement intelligence

Requirement extraction, functional/non-functional classification, ambiguity analysis, manual review, and version history.

## v0.4.0 — Traceability

Artifact management, manual and suggested requirement links, confidence review, matrix visualization, and coverage metrics.

## v0.5.0 — Change intelligence

Requirement version comparison, affected-artifact discovery, risk scoring, severity, and persistent impact reports.

## v0.6.0 — AI project assistant

Project-isolated semantic indexing, ChromaDB, Sentence Transformers, Ollama answers, citations, search, and conversation history.

## v0.7.0 — Analytics and professional interface

Project health, analytics, exports, responsive design, consolidated validation, accessibility improvements, branded application shell, and repository cleanup.
