# ATLAS Demonstration Script

## Preparation

- Start Docker services.
- Confirm migration head and health endpoints.
- Sign in as an administrator and keep a normal user account available.
- Use one project with a processed SRS and representative data.

## Ten-minute demonstration

1. **Platform overview:** show the project dashboard and all nine project modules.
2. **Document intelligence:** upload a valid PDF/DOCX and show extraction metadata.
3. **Requirement intelligence:** extract requirements and explain type, confidence, and ambiguity.
4. **Governance:** request a review, approve a requirement, and show a baseline.
5. **Traceability:** create an artifact, accept a link, and show coverage/matrix changes.
6. **Impact analysis:** edit a requirement and explain direct/transitive impact and risk.
7. **Test intelligence:** show linked steps, approval status, and requirement coverage.
8. **AI Assistant:** ask a project question and point to numbered source citations.
9. **Release readiness:** evaluate quality gates, resolve a blocker, and show readiness.
10. **Administration:** show existing users, project oversight, audit events, and system health.

## Closing message

ATLAS connects document evidence, structured requirements, governance, engineering artifacts, change impact, tests, AI-grounded knowledge, analytics, and release decisions in one traceable platform.
